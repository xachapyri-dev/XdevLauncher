# Хачапури dev Launcher
Лаунчер созданный небольшой студией "Хачапури dev" из Кирова. В этом лаунчере вы можете скачивать игры от Хачапури dev или от других авторов. Но также вы можете создовать кастомные темы для страницы через ```css``` или создать экран приветствия, а также настроить лаунчер по вашему вкусу

### [Скачать последнюю версию (последний релиз)](https://github.com/kroshidanielstudio/Xdev_Store/releases/latest)

## Что надо для работы?
- Windows 10 и выше
- Установленный .NET Framework 4.8.1 и *WebView2 Runtime последний версии

> *WebView2 Runtime нужен для версий старше 2.1.0
